🎓 Student Management System

A Java-based Desktop Application designed to manage student records efficiently. This system performs complete CRUD operations (Create, Read, Update, Delete) and provides an easy-to-use interface for handling student data in a structured way.

📌 Project Overview

The Student Management System is built to simplify the process of managing student information in schools or colleges. It allows administrators to add, search, update, and delete student records seamlessly.

This project demonstrates:

Java GUI development using Forms

Database connectivity

Implementation of full CRUD operations

Clean project structure

🚀 Features

✅ Add new student records
✅ View/Search student details
✅ Update student information
✅ Delete student records
✅ Login authentication system
✅ User-friendly GUI interface
✅ Structured database storage

🛠️ Technologies Used
Technology	Purpose
Java (Core Java)	Application logic
Swing / Java Forms	GUI Development
JDBC	Database connectivity
MySQL	Database management
NetBeans / IDE	Development environment

➤ Create

➤ Read

Search and display student information.

➤ Update

Modify existing student details.

➤ Delete

Remove student records permanently.
